# Agent instructions

This repo makes a short vertical video (1080x1920, 30 fps) with Claude Code: idea, character, song or voice, animation, timings, an edit written as HTML + GSAP, and a render with [HyperFrames](https://github.com/heygen-com/hyperframes). Steps 1 to 4 live in `prompts/generate/`, written from provider docs; never describe them as tested. The three examples use existing footage and run steps 5 to 7:

| Example | Footage | Timings | Data |
|---|---|---|---|
| `examples/wing-it` | WING IT! (Blender Studio, CC BY 4.0), cut to 9:16 shot by shot | story events read from frames | `shots.json`, `events.json` |
| `examples/spin-count` | a Pixabay clip and a Pixabay track | spin marks read from frames, a beat grid | `spins.json`, `beats/` |
| `examples/handwash-song` | CDC's public-domain "Happy Handwashing Song" | Whisper words aligned to `lyrics.txt` | `transcript.json` |

## Layout

```text
docs/                    one chapter per step, gotchas.md, img/ (README previews)
prompts/                 00-brief.md, generate/ (steps 1-4), edit/ (steps 5-7)
skills/character-video/  the Claude Code skill for the whole pipeline
scripts/                 zero-dependency Node ESM; every script has --help
examples/<name>/
  build/index.template.htm   source of truth for the composition
  index.html                 generated by scripts/build.mjs
  assets/                    media (gitignored)
  renders/  snapshots/       outputs (gitignored)
```

## Commands

```bash
export HYPERFRAMES_NO_TELEMETRY=1        # PowerShell: $env:HYPERFRAMES_NO_TELEMETRY = "1"
npx hyperframes@0.8.143 browser ensure   # once
npm run fetch:wing && npm run build:wing && npm run lint:wing
npm run fetch:spin && npm run build:spin && npm run lint:spin
npm run fetch && npm run align && npm run build && npm run lint   # handwash-song
npm run render:wing     # render + edge fix, after the human's OK (also render:spin, render)
npx hyperframes@0.8.143 snapshot examples/wing-it --at 0,0.05,3.6,11,22.2,26.3,29.1,31.6 --no-end --describe false
npx hyperframes@0.8.143 snapshot examples/spin-count --at 0.8,2.6,8.9,20.6 --describe false
npx hyperframes@0.8.143 snapshot examples/handwash-song --at 3.6,14.0,26.5 --describe false
npx hyperframes@0.8.143 render <exampleDir> -q draft -o <exampleDir>/renders/draft.raw.mp4   # draft, after the human's OK
node scripts/build.mjs <exampleDir> --check   # exit 1 when index.html is stale
npm run check-links                           # relative links and anchors in all Markdown
```

## Hard rules

1. **Edit the template, never `index.html`**, then run `node scripts/build.mjs <exampleDir>`. Keep `.htm`: `hyperframes preview` writes `data-hf-id` into every `*.html` with `data-composition-id`. After a preview, rebuild and check `git diff`.
2. **Timings come from data.** handwash-song keys sung events to `TRANSCRIPT[i]`, with `LINES` and `SLOTS` as word indices. spin-count keys spins to `SPINS` (source times / 0.85, matching `spins.json`) and the pulse to `BEAT0`, `BEAT`. wing-it keys `ITEMS`, `GADGETS` and cues to `events.json`; `shots.json` is the cut. Change code and data together and check each new event with a frame grab. Literal seconds only for the intro, short offsets, `VIDEO_END` and the total duration (= root `data-duration`).
3. **`transcript.json` comes from `scripts/align-lyrics.mjs`.** Fix the input and re-run. Report any hand-corrected word in the reply and the commit message.
4. **Never point `hyperframes transcribe --dir` at an example folder.** It overwrites `transcript.json` and rewrites `const TRANSCRIPT` in the HTML. `hyperframes beats` is safe.
5. **Never commit media** (`*.mp4`, `*.webm`, `*.mp3`, `*.wav`, images, `gsap.min.js`, `renders/`, `snapshots/`, `assets/source/`), except the previews in `docs/img/`. Full renders go up as release assets.
6. **Probe every input and output** with `node scripts/probe.mjs`. Never assume 44.1 kHz; 48 kHz AAC in a render is expected.
7. **Lint before any render**: 0 errors (`nested_structure_needs_subcomposition` warnings are expected). Encode video with a keyframe every second at a width that is a multiple of 16 (1088 for full frame).
8. **Stop before rendering.** Show snapshots, wait, render a draft, wait, then render delivery.
9. **Fix the right edge after every render.** With ffmpeg 8.1.2 (gyan.dev Windows build), HyperFrames 0.8.143 renders carry an 8 px black strip at x 1072 to 1079 (repro: `ffmpeg -f lavfi -i "color=c=white:s=1080x64,format=yuv420p" -frames:v 1 -vf format=gbrp out.png`; clean with `-cpuflags 0`). Render to `<name>.raw.mp4`, run `node scripts/fix-right-edge.mjs <name>.raw.mp4 <name>.mp4` and report its mode. Compare raw renders in determinism checks. Make handwash-song previews from before 25.17 s, where the CDC end card starts.
10. **Pin HyperFrames**: always `npx hyperframes@0.8.143`. An upgrade means lint, snapshots, the framemd5 check, the edge check and updated numbers in the docs. Rerun the rule 9 repro after any ffmpeg change.
11. **Outbound calls.** Pass `--describe false` to every `snapshot`. Do not run `hyperframes feedback` or `usage` unless asked.
12. **Paid generation** needs the human's OK per batch, with model, provider, quantity and list price stated. Log every call in `costs.csv`, rejected takes included.
13. **Secrets** come from the environment. Never print them, write them to a file, paste them into a prompt or commit `.env`.

## Composition contract

- One `gsap.timeline({ paused: true })`, registered synchronously as `window.__timelines["<data-composition-id>"]`.
- No `Math.random` (use a seeded PRNG), `Date.now`, `performance.now`, `requestAnimationFrame`, timers or `fetch`.
- Media timing comes from `data-start`, `data-duration`, `data-media-start`; never play, pause or seek from script. Every `<video>` is `muted` (or `data-has-audio="true"`); every `<audio>` has an `id`, or the render is silent.
- Never `translate(-50%,-50%)` an element GSAP moves, tween `visibility`, `display` or `autoAlpha` on `.clip`, or measure the DOM inside tweens.
- No DOM writes from timeline callbacks: tween `textContent` with `snap: { textContent: 1 }`. A write can fail HyperFrames' draw-element check. wing-it's `#alt-num` still does it, to match its published render; do not copy it.
- A `fromTo` applies its from-state at build time. Hide every not-yet-visible from-state; use `to` or `immediateRender: false` on a property an intro tween animates from hidden.
- GSAP 3.14.2 from `assets/gsap.min.js`. Fonts Poppins and Inter, named with `font-family`, never only in the `font:` shorthand.
- Set the root `data-duration` in HTML, never from JS.

## Before you report done

1. Build the example you changed and `--check` the others.
2. Lint with 0 errors; snapshot and read `snapshots/contact-sheet.jpg`.
3. Changed timing: snapshot 0 s, 0.05 s and every affected event.
4. Changed a doc or heading: `npm run check-links` passes.
5. Say what you checked and what you did not.

## Writing style

Plain English, short sentences, "you" for instructions. No em dashes, emojis, marketing words, "we" or "our". No hardware specs or personal setup details. No other creators or social accounts; vendors, tools and the license credits above are fine. Every number is measured on this repo or cited with a URL.
